# Real vehicle imagery — V0.6

The production catalog uses one dedicated real-vehicle asset per current marketplace product, served from the Valtera Cloudinary CDN under `valtera/real-vehicles/<slug>.webp`.

Rules:
- one distinct base photo per product slug;
- no generic motorcycle/car image reused across unrelated models;
- generated/AI imagery may be used only as an optional paint-color variant, never as the canonical model photo;
- the original editorial image remains only as a technical fallback if a real asset is unavailable;
- portfolio project only; Valtera Motori is fictional and not affiliated with the represented manufacturers.

Current coverage: 32/32 canonical V0.6 base products have dedicated real-vehicle assets in Cloudinary.
